# 某某汽车 · 制动踏板极限测试

一个极简风格的浏览器小游戏：把车加速到 100 km/h 以上，在踏板断裂极限（1500 N）之内把车刹停。

**单文件、零依赖**：全部 HTML / CSS / JavaScript 都在 `index.html` 里，双击即可在本地打开。

## 直接在线玩

推送并开启 GitHub Pages 后，访问：

```
https://<你的用户名>.github.io/brake-test/
```

## 玩法

1. 开局先分配 **10 点技能点**，四项各有取舍（每项上限 10 级）
2. 点击开始，车辆全速加速；**100 km/h 之前刹车锁定**
3. 达到 100 km/h 后刹车按钮变红解锁：**长按刹车**，按住**上滑加力**、**下滑卸力**
4. 按国标，踏板力到 **500 N 即输出最大制动效能**；继续加力只会逼近 **1500 N** 的踏板断裂极限
5. 踏板一旦断裂，液压制动彻底失效，仅剩电机动能回收与风阻；此时要完成 **3 次「回过神」单击检定**，通过后长按 2 秒拉起**电子手刹**紧急制动
6. 结算会给出制动总距离、断裂后滑行距离、回收动能等

## 四个技能

| 技能 | 0 级 | 10 级 |
|---|---|---|
| **平心定气** | 每上滑 5 px +750 N（踩下即断） | 每 5 px +143 N，收得住 |
| **从容自若** | 3 次回神判定 | 免判定，直接拉手刹 |
| **疑神疑鬼** | 0-100 km/h 约 5.6 s | 约 25 s |
| **眼明手巧** | QTE 高亮区 10%（窗口 0.09 s） | 46%（窗口 0.41 s） |

## 物理模型

- 整车质量 3.2 t
- 摩擦制动：踏板力 500 N 达满效能，最大减速度 7.0 m/s²（μ≈0.71）
- 电机动能回收：功率上限约 100 kW，`a = min(P/mv, K·v)`，低速按 `(v/3)²` 收敛
- 风阻 `0.42v² + 320 N` 滚阻，固定 1/240 s 步长积分
- 电子手刹（后轮）额外提供约 2.5 m/s²

所有数值均为通用工程参数，车型名称为虚构占位。

## 部署到 GitHub Pages

```bash
git init
git add index.html README.md
git commit -m "Add brake test game"
git branch -M main
git remote add origin git@github.com:<用户名>/brake-test.git
git push -u origin main
```

然后在仓库 **Settings → Pages** 里把 Source 设为 **Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存后等一两分钟即可。
